# Go-kafka-microservice
Microserviço em Go que consome mensagens do Kafka, processa payloads e envia para um serviço REST via PATCH.

# Para executar:

sudo apt-get update && sudo apt-get install -y \
    build-essential \
    pkg-config \
    libssl-dev \
    libsasl2-dev \
    zlib1g-dev \
    libzstd-dev \
